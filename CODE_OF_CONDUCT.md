# Code de conduite

Ce projet adopte le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez respectueux, accueillants et constructifs. Le harcèlement, les attaques personnelles et les propos discriminatoires ne sont pas tolérés, dans les issues, les discussions, les PR et partout où le projet est représenté.

Pour signaler un comportement, écrivez au mainteneur, [@tbsrgt](https://github.com/tbsrgt), par un message privé sur GitHub. Chaque signalement est traité avec discrétion.
